## 🐍 Project Overview

The objective of this project is to develop deep learning classification models to automatically process snake images from a test dataset without manual intervention. The solution covers two main tasks:

* Multi-class classification for identifying snake species.
* Binary classification for determining whether a snake is venomous or non-venomous.
